# Pac-Man Game

A classic Pac-Man game implementation using Python and Pygame.

---
## Features

- Classic Pac-Man gameplay with yellow Pac-Man character
- Multiple ghost enemies with different colors
- Pellet collection system
- Multiple levels with increasing difficulty
- Score tracking
- Smooth mouth animation for Pac-Man
- Collision detection for pellets and ghosts
- Level progression system
---
## Installation

1. Install Python 3.x from [python.org](https://www.python.org/downloads/)
2. Install required dependencies:

   pip install pygame
---
# How to Play

Run the game:

python pac_man_game.py

# Controls:

↑ (Up arrow) - Move Pac-Man up
↓ (Down arrow) - Move Pac-Man down
← (Left arrow) - Move Pac-Man left
→ (Right arrow) - Move Pac-Man right

# Game Rules:

Collect white pellets to score points (10 points per pellet)
Complete levels by collecting all pellets
Avoid the ghosts - touching a ghost ends the game
Each level adds more ghosts and increases difficulty

# Game Mechanics:

Pac-Man moves in grid-aligned steps
Ghosts move in synchronized patterns
Pellets are placed in a grid pattern
Score is displayed at the top of the screen
Level number is shown next to the score
Game ends when Pac-Man collides with a ghost
